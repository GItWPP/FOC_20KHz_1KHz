# UART命令与V6遥测协议

接线及操作见根目录 [readme.md](../readme.md)。


所有多字节字段大端，CRC16-CCITT多项式0x1021、初值0xFFFF，不反射。

下行固定16字节：

| 字节 | 内容 |
|---|---|
| 0..1 | 5A A5 |
| 2 / 3 | 版本1 / 长度16 |
| 4..5 | 请求序号u16 |
| 6 / 7 | opcode / key |
| 8..11 | value32；角度为signed毫度，其余为无符号数 |
| 12..13 | 保留0 |
| 14..15 | 覆盖0..13的CRC |

opcode：1心跳(key/value=0，不改变上条回执)、2写、3读(value=0)、4电机软复位(key/value=0)。key：01=start、02=mode、03=rpm、04=角度毫度、05=Iq毫安、10/11=速度Kp/Ki、12/13=电流Kp/Ki、14=位置Kp（key均十六进制）。系数编码为值×65536。解析器丢弃2ms超时的半帧；坏CRC不执行、不续命。

回执状态：0成功、1未知操作、2未知参数、3数值非法、4需先停机、5尚未重新使能、6驱动未就绪、7电机故障、8忙、FF尚无回执。回执确认参数已接收/执行，不代表定位运动已完成；完成请检查position_settled及误差。

上行V6固定96字节、1kHz，约占1.5Mbps链路64%：

| 字节 | 内容 |
|---|---|
| 0..3 | A5 5A 06 60 |
| 4..5 | 遥测序号u16 |
| 6 | bit0=start、1=drive、2=run、3=indexed、4=calibrated、5=看门狗固定1、6=host_alive、7=saturated |
| 7 / 8 / 9 | 电机状态 / 故障码 / 速度环状态 |
| 10..11 / 12..13 | 设定rpm u16 / 斜坡rpm s16 |
| 14..17 | 实际rpm×256，signed32 |
| 18..25 | Id、Iq、Id参考、Iq参考，各signed16毫安 |
| 26..27 / 28..29 | Iq上限u16毫安 / 单圈位置u16计数 |
| 30..37 / 38..45 / 46..53 | 实际/目标/误差，各signed64毫度；误差=目标−实际 |
| 54 | 位置状态：bit0模式、1零点建立、2到位、3目标限幅、4位置越界、5模式待切换 |
| 55 | bit0远端使能、1主机在线、2请求定位模式、3启动请求、4角度换算忙、7控制固件标记 |
| 56..57 / 58 / 59 / 60 / 61 | 回执序号 / opcode / status / key / 保留0 |
| 62..65 | 回执value32，读操作为读回值；角度为signed毫度请求值 |
| 66..85 | 五个u32 Q16系数：速度Kp/Ki、电流Kp/Ki、位置Kp |
| 86..89 | ADC有效帧计数u32，电机软复位后清零 |
| 90..91 / 92..93 | CRC正确命令帧数u16 / 解析及拒绝命令错误数u16，均自然回绕 |
| 94..95 | 覆盖0..93的CRC |

角度输入采用39拍顺序除法，按 `round(毫度×128/5625)` 转计数；遥测采用短流水按 `round(计数×5625/128)` 转毫度。统一在报文边界拍保存参数、状态及位置，转换期间不混入下一拍字段。Python还保留内部计数和圈数字段用于旧统计/离线兼容，主要页面使用度。
